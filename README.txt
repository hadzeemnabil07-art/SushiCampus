SUSHI BITES — ORDERING WEBSITE

FILES
- index.html = website
- style.css = design
- script.js = menu, cart, pricing and WhatsApp ordering

HOW TO USE
1. Keep all three files in the same folder.
2. Open index.html in Chrome/Edge.
3. Before taking real orders, open script.js.
4. Find:
   const WHATSAPP_NUMBER = "60123456789";
5. Replace 60123456789 with your own WhatsApp number.
   Malaysia example: 60123456789
   Do not include +, spaces or dashes.

PRICING
- 1–4 pieces: RM1.70 each
- 5–9 pieces: RM1.60 each
- 10+ pieces: RM1.50 each

ORDER SYSTEM
The customer adds items, enters their name, phone and notes, then clicks
"Send order via WhatsApp". WhatsApp opens with a complete order message.

IMPORTANT
This version does not require a server or database. Orders are sent directly
to your WhatsApp. If you later want a dashboard, order database, stock
tracking, online payment, or orders sent to multiple staff members, the site
can be upgraded to use a backend/database.
